# DXPart.live - Deriv Trading Platform

A comprehensive third-party trading platform for Deriv with advanced analysis tools, live data streaming, trading bots, market scanner, bot builder, and trading charts.

## Features

### 📊 Analysis Tools
- Technical indicators (RSI, MACD, Bollinger Bands)
- Advanced charting with TradingView Lightweight Charts
- Market analysis tools
- Trading signals

### 💰 Live Data
- Real-time price feeds via Deriv WebSocket
- Market data streaming
- Historical data management
- Multi-asset support

### 🤖 Trading Bots
- Automated trading strategies
- Bot management dashboard
- Performance tracking
- Strategy backtesting

### 🔍 Market Scanner
- Real-time market monitoring
- Symbol screening
- Alert system
- Trend detection

### 🛠️ Bot Builder
- Visual bot creation interface
- Drag-and-drop workflow builder
- Strategy templates
- Backtesting simulation

### 💬 Trading Chat
- Community discussions
- Trade sharing
- Real-time notifications

## Tech Stack

**Frontend:** React 18, Next.js 14, TypeScript, Tailwind CSS, Redux Toolkit, Socket.io
**Backend:** Node.js, Express, TypeScript, MongoDB, Redis, Bull Job Queue
**DevOps:** Docker, Docker Compose

## Installation

```bash
git clone https://github.com/LAURANCE792/Dxpart.live.git
cd Dxpart.live
npm run install:all
```

## Development

```bash
npm run dev
```

Frontend: http://localhost:3000
Backend: http://localhost:5000

## Using Docker

```bash
docker-compose up -d
```
